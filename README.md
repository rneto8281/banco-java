Projeto de banco em Java puro focado em Orientacao a Objetos. Trilha os quatro pilares da POO de forma prática, como heranca, polimorfismo e encapsulamento. Roda direto no terminal pelo VS Code com um menu interativo completo para criar contas, sacar, depositar e transferir. O setup é leve e nao exige bibliotecas externas. Ideal para turbinar o seu GitHub e mostrar dominio em logica backend raiz.
